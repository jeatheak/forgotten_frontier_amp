# The Forgotten Frontier: AMP template

CubeCoders AMP template for the dedicated server of The Forgotten Frontier. The game and the server are released in this
repository too: the template downloads the server from its
[releases](https://github.com/jeatheak/forgotten_frontier_amp/releases).

In AMP open *Configuration > Instance Deployment > Configuration Repositories*, add `jeatheak/forgotten_frontier_amp:main`,
press *Fetch*, refresh the page and create an instance of *FF / The Forgotten Frontier*.

The repository name has no hyphens on purpose: AMP cannot upgrade instances from a repository whose owner or name
contains a hyphen.
